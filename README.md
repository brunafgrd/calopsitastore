# 🐦 Calopsita Store

Site responsivo desenvolvido em grupo durante a graduação em Análise e Desenvolvimento de Sistemas.

O projeto simula uma loja especializada em calopsitas, com páginas de apresentação, produtos, novidades e contato.

## 💻 Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## 📄 Páginas

- Página inicial
- Sobre
- Produtos
- Novidades
- Contato
- Referências

## 👩‍💻 Minha contribuição

Neste projeto, fui responsável principalmente pelo desenvolvimento da:

- Página inicial
- Navegação do site
- Footer
- Estrutura e organização da interface
- Responsividade

Também participei da implementação e organização dos elementos visuais e interativos do projeto.

## ✨ Funcionalidades

- Layout responsivo
- Navegação entre páginas
- Banner/carrossel na página inicial
- Elementos interativos com JavaScript
- Formulário de contato
- Organização semântica com HTML5

## 🎨 Interface

O projeto foi desenvolvido com foco em uma interface simples, responsiva e voltada para a experiência do usuário.
